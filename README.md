MILO'S MAGICAL WORLD — WEBSITE

Files:
- index.html — complete responsive website
- hero.png — homepage artwork

IMPORTANT:
Keep index.html and hero.png in the SAME folder.
Open index.html in Chrome/Edge/Firefox to run it locally.

The page also contains a fallback illustration made from HTML/CSS, so the site remains usable if hero.png is unavailable.

For HTTPS hosting:
Upload both files to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. The host supplies the https:// address.
